# Questions for the organizers

Doubts that the rules, the template and the organizers' repos don't answer,
and that change design decisions. Before adding one, check whether the
[rules](https://airclub-udesa.github.io/jar_site/reglamento/), the
[template](https://github.com/AIRclub-UdeSA/jar_challenge), the
[simulator](https://github.com/AIRclub-UdeSA/yahboom_rosmaster) or the
[physical robot repo](https://github.com/AIRclub-UdeSA/physical_rosmaster)
answer it.

Questions are sent to airclub@udesa.edu.ar. States: **Not sent**, **Sent**,
**Answered**. When an answer arrives, update the state and write it in the last
column. Questions and answers stay in Spanish, as sent.

| Question | Why it matters | State | Answer |
| --- | --- | --- | --- |
| ¿Las cajas reales miden lo mismo que en el simulador (0,25 × 0,25 × 0,30 m)? ¿Se puede poner ese tamaño en `params/`? | Used to estimate the box center from its visible face. Half the width (12.5 cm) is half the 25 cm tolerance. | Not sent | |
| ¿Cuándo cierran las entregas? | The template mentions a delivery cutoff, but neither the rules nor the site give the date. It sets the real development deadline. | Not sent | |
| ¿Qué tamaño tiene la arena de competencia? ¿Se parece a los laberintos de práctica (6,1 × 5,05 m a 6,1 × 6,15 m)? | Decides whether the 5-minute bonus is reachable and how to size the coverage route. | Not sent | |
